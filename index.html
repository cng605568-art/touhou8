Source-built browser port

Imperishable Night

Select th08.dat and thbgm.dat from a legally obtained TH08 installation. The game archive is copied only into volatile session memory, while the music archive is range-read from its browser File object. Neither file is uploaded, bundled, or persisted by this page.

Settings, scores, replays, backups, and snapshots can be stored in this browser and restored on reload. Use Save now before closing the tab. Clearing this site's browser data removes them. The game's running state itself is not a mid-stage save state.

Landscape is recommended for the most comfortable play. Your TH08 data stays in this browser session.

Keyboard: arrow keys move, Z confirms/fires, X cancels/bombs, Shift focuses, and Esc pauses.
